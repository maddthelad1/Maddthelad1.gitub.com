# زرین — فروشگاه طلا و جواهرات

یک قالب فروشگاه آنلاین فارسی و راست‌به‌چپ با تم طلایی و صورتی.

## فایل‌ها

- `index.html` — ساختار کامل صفحه
- `styles.css` — طراحی، رنگ‌ها، ریسپانسیو و اجزای رابط کاربری
- `script.js` — منوی موبایل، سبد خرید، اعلان‌ها و خبرنامه
- `assets/design-reference.png` — تصویر طراحی تولیدشده برای الهام/هدر
- `README.md` — راهنما

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای تجربه بهتر می‌توانید پروژه را با یک سرور محلی ساده اجرا کنید:

```bash
python -m http.server 8000
```

سپس به `http://localhost:8000` بروید.

## نکته

قیمت‌ها و اطلاعات تماس نمونه هستند و برای استفاده واقعی باید با اطلاعات فروشگاه جایگزین شوند. بخش پرداخت نیز نمایشی است و برای فروشگاه واقعی باید به بک‌اند و درگاه پرداخت متصل شود.
